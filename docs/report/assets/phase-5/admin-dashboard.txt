4. BANNER TRANG CHỦ (/quan-tri/banner và /)
==============================================================================
python -m scripts.seed_banners   -> 3 banner (ảnh gradient 1680×640 PNG tự sinh, tải lên
                                    banners/ qua service); chạy lại -> 0 banner mới
trang chủ                        -> carousel 3 slide, ảnh tải được (naturalWidth 1680),
                                    link /khoa-hoc, /khoa-hoc?q=python, /bang-xep-hang;
                                    ở 1280px khung 1120×428 (21:8)
"Thêm banner" + ảnh 1260×480 chọn qua ô tệp -> xin URL ký -> PUT thẳng lên MinIO ->
                                    banner thứ 4 "Đang hiện", ảnh tải được (naturalWidth 1260)
"Tắt"                            -> "Đang tắt"; GET /api/v1/banners chỉ còn 3 banner seed
"Đưa lên"                        -> đứng thứ 3
"Xóa"                            -> dòng biến mất; URL ảnh cũ trên bucket trả 404
