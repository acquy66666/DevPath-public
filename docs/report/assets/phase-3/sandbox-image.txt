2. ĐỐI CHỨNG: BASE python:3.12-slim-bookworm  ↔  IMAGE SANDBOX
------------------------------------------------------------------------------
Cùng một đoạn code, cùng một bộ cờ container. Cột trái là thứ sẽ xảy ra nếu
chấm bài bằng image Python thông thường.

• Chạy dưới uid/gid nào (không truyền --user)
    base    : 0 0
    sandbox : 10001 10001
• Thư mục làm việc
    base    : /
    sandbox : /sandbox
• pip trên PATH / module ensurepip
    base    : /usr/local/bin/pip True
    sandbox : None False
• Gói bên thứ ba cài sẵn
    base    : ['pip']
    sandbox : []
• Ghi vào /usr/local/lib khi CÓ --read-only
    base    : EROFS
    sandbox : EROFS
• Ghi vào /usr/local/lib khi BỎ --read-only
    base    : GHI ĐƯỢC
    sandbox : EACCES
• Output in ra rồi thoát bằng os._exit (không flush)
    base    : 
    sandbox : dòng đã in
• hash('devpath') — chạy hai lần liên tiếp
    base    : 4562430851089317239 / -4360033887283379753
    sandbox : -6433446586248150867 / -6433446586248150867
• Encoding của stdout
    base    : utf-8
    sandbox : utf-8

• Binary có bit setuid/setgid còn sót trong image
    base    : ['/usr/bin/chage', '/usr/bin/chfn', '/usr/bin/chsh', '/usr/bin/expiry', '/usr/bin/gpasswd', '/usr/bin/mount', '/usr/bin/newgrp', '/usr/bin/passwd', '/usr/bin/su', '/usr/bin/umount', '/usr/sbin/unix_chkpwd']
    sandbox : []
