Vòng lặp for trong Python

Vòng lặp for đi qua từng phần tử của một dãy, theo đúng thứ tự. Xem thêm tài liệu chính thức của Python.

for i in range(3):
    print("Lượt", i)

Những điều cần nhớ

  • range(n) sinh các số từ 0 tới n − 1.
  • Thụt lề quyết định câu lệnh nào nằm trong vòng lặp.
Người học thường quên rằng range không gồm số cuối.
