Học trên DevPath thế nào

  1. 1

    Chọn một khóa

    Khóa nào cũng có bài xem trước để học thử. Khóa miễn phí thì đăng ký là học được ngay.

  2. 2

    Học và nộp bài

    Bài code được chấm trong sandbox, kết quả từng test hiện ngay. Kẹt chỗ nào thì hỏi trợ giảng AI.

  3. 3

    Giữ nhịp học

    Mỗi bài xong được XP. Học mỗi ngày để giữ chuỗi; học hết khóa thì nhận chứng chỉ.
