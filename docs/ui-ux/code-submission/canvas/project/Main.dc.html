Cho một dãy số nguyên, đếm xem có bao nhiêu số chẵn.

Đầu vào: dòng đầu là số nguyên n — số lượng phần tử. Dòng thứ hai là n số nguyên cách nhau bởi dấu cách.

Đầu ra: một số nguyên duy nhất — số lượng số chẵn trong dãy.

Giới hạn: 1 ≤ n ≤ 1000, mỗi số trong khoảng -10^6 đến 10^6.
