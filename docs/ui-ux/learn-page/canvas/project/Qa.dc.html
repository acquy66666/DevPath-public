Hai lệnh nhận hai kiểu dữ liệu khác nhau. Với một số thực, int() bỏ phần thập phân nên int(3.5) là 3. Với một chuỗi, int() chỉ đọc được chuỗi viết đúng một số nguyên, nên "3.5" bị từ chối. Muốn đi từ chuỗi đó sang số nguyên thì qua số thực trước: int(float("3.5")).
